# Simple Tasks

## Introduction
현대인들은 복잡한 일정들과 상황 가운데 있다.
이것은 당장 해야할 일들을 하지 못하게 하는 결과를 초래한다.
복잡한 일정들과 상황을 파악하고 유연하게 당장 해야 할 일을 추론하기 위해서는 '지능'이 필요하다.

Simple Tasks는 이 '지능'을 인공지능으로 대치하여 단순하게 일정을 처리할 수 있도록 도와주는 솔루션이다.

## Target
목표 타겟은 "개인"으로 한다.
"업무"와 다르게 명확한 작업 명세가 없기에 해야 할 일을 추론하는 서비스에 핏한 목표이다.
