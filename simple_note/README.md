# Simple Note

## Introduce
현대인들은 복잡한 일정들과 상황 가운데 있다
그런 일정 가운데서 순간적으로 떠오르는 생각들은 곧바로 적지 못하고 휘발성으로 날아가 버린다.
이 생각들은 창작물을 만드는데 사용되는 재료가 될 수 있는 가능성을 지녔다.

이렇게 떠오른 생각들을 모아 하나의 창작물을 만든 사람이라면
또한 그것이 사람들에게 인정받는다면 자아실현의 욕구를 만족시킬 것이다.

여기서 중요한 점은 생각을 정리하고 해당 생각을 기반으로 창작물이 만들어지는데,
사용자의 익명성이 보장되어야 한다는 것이다.
뿐만 아니라 성공적인 경험을 위해서 다작을 해야 하는데,
여기서 인공지능을 사용한 자동화의 필요성이 있다.
(성공적인 경험을 위해서 다작을 해야 한다는 것은 가설이다.)
