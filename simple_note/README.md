# Simple Note

## Introduce
지식 시스템을 확장시키기 위해서는 직감에 따른 순간적으로 떠오르는 생각들이 필요하다.
그렇지만 이는 휘발성이고, 그렇기에 우리는 이러한 생각들을 기록한다.

그것은 현재는 그것을 생각하지 않아도 될 때이기에 적는 것일까?
아니면 메모를 사용해서 조금 더 몰입할 수 있게 하기 위한 것일까?

숀케 아레슨이 말한 것에 따르면 둘 다이다.
그럼에도 이 둘은 현재 하고 있는 일을 몰입할 수 있게 하는 것이라는 공통점을 가지고 있다.
현재 생각해지 않아도 되는 일을 배제함으로써,
모호한 감각을 명확한 언어로 표현함으로써,
현재의 일을 단순화하여 더 확장가능하게 만드는 것이다.

이것을 사용하여 어떤 창작물을 만드는 지는
읽는 사람에 달려 있다.

이를 위해서 인공지능을
1. 연관관계 파악
2. 모순 탐지
3. 출력 피드백
의 역할로 사용하고, 
이 자체로 별도의 서비스가 될 수 있도록 구성한다.

이것은 행위 자체가 보상이 될 때 지속가능하다라는 생각에 근거한다.
